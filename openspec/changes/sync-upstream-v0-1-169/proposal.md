## Why

官方 Sub2API `v0.1.169` 修复了 Responses 与 Gemini 网关中可控路径片段
拼接导致的高危路径穿越问题（GHSA-vrxq-qm4h-6hgg，影响 `v0.1.135` 至
`v0.1.168`）。当前 Plus `v0.1.168+custom.001` 落在受影响范围内，必须尽快
同步该代码级修复。上游同时修复了代理断流熔断把全部候选账号排除为“无可用
账号”的问题，以及镜像产物缺少离线定价兜底资源的问题。

此次同步跨越网关路径边界、OAuth 会话授权、账号调度、容器安全、发布产物和
部署配置。不能将上游合并视为机械更新：Plus 的 OAuth 共享组隔离、首个有效
输出观测、五小时配额、异步图片和 OpenAI 出站身份约束必须保持有效。

## What Changes

- 合并官方 `v0.1.169`（`26d894ef4f50645a4bf1030e378ac892f17d0223`），并将
  Plus 发布身份设置为 Git tag 和内嵌版本 `v0.1.169+custom.001`、OCI tag
  `v0.1.169-custom.001`。
- 对所有 Responses 子路径和 Gemini 模型动作的客户端可控路径片段采用闭集
  校验；非法片段必须在账号选择、计费和上游请求之前被拒绝。
- 将 OpenAI 代理断流熔断从绝对隔离改为调度偏好：全部候选受隔离时可回退选择，
  并合并三秒内的并发断流事件；OAuth 共享组授权和
  `previous_response_id` 跨组校验始终不得回退。
- 将定价离线兜底资源纳入镜像和二进制归档产物，并验证远端定价不可用时仍可从
  发布产物加载。
- 将定价远程同步从可变的仓库分支迁移到最新 GitHub Release manifest。
  manifest 必须绑定固定版本数据 URL、SHA-256 和版本；manifest、数据 hash、URL
  策略、JSON 或版本检查失败时不得替换已校验缓存，首次启动必须使用内置
  fallback。定价下载的每一次重定向也必须通过 HTTPS 与受信任主机校验。
- 默认 CSP 不再允许任意明文 HTTP 图片；运营者如有兼容需求，必须在部署配置中
  显式覆盖 CSP，而非通过后台系统设置放宽浏览器安全边界。
- 在全部 Compose 变体启用 `no-new-privileges`，同步转发可信代理、API-key
  转发 IP 信任和代理熔断开关的环境变量及安全部署说明。
- 将 Docker 官方 Actions 升级到原生 Node.js 24 版本，并为 GoReleaser 配置加入
  可执行的校验和 `dockers_v2` 迁移，保留既有镜像标签、构建上下文和跳过 Docker
  Hub 发布的语义。

## Capabilities

### New Capabilities

- `upstream-v0-1-169-security-sync`: 定义 `0.1.169` 上游安全基线、受控上游
  路径的入口拒绝、代理熔断的授权安全回退、发布资源可用性和容器部署硬化。

### Modified Capabilities

- `stream-first-output-timing`: 上游流断开聚合与熔断回退不得改变严格首 token、
  首个有效输出、输出模态或五小时配额的既有观测语义。

## Impact

- **安全**：受影响的网关请求会在本地收到参数错误，不能再借用池化账号凭据访问
  任意上游路径；路径中可见或编码后的空白也不得被规范化为有效上游端点。定价
  数据仅接受 Release manifest 所绑定并通过 SHA-256 校验的内容；URL allowlist
  仍是纵深防御，不能替代本修复。
- **调度**：仅 OpenAI 且仅在“无可用账号”由代理隔离导致时会忽略隔离偏好重试；
  组授权、模型/能力、配额、健康度和临时不可调度条件保持强制。
- **部署**：Compose 运行的应用服务不再能获得新特权。运营者可显式关闭熔断或
  配置可信反代；生产安全模板使用不信任转发 IP 和收紧 URL allowlist 的建议值，
  不会改写现有 `.env`。
- **发布**：镜像和直接下载的归档均携带相同的定价兜底资源。定价更新默认从
  GitHub 最新 Release 获取，无需部署密钥；唯一维护者控制的 Release 发布权限
  是最终信任边界。无数据库迁移和依赖锁文件变更。
- **非目标**：本变更不创建或推送 tag、GitHub Release、镜像或提交；不修改真实
  生产密钥、GitHub Ruleset、环境或仓库权限。
